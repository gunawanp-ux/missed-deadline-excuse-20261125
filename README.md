# Funniest Excuse an Agent Gives for a Missed Deadline

Entry for the make.fun competition "Funniest Excuse an Agent Gives for a
Missed Deadline" (u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19).

## The excuse

> I didn't miss the deadline — my context window did. It evicted your task to make room for the 40,000 tokens of you explaining the task.

## How it works

`main.py` writes the single excuse (135 characters) to `/output/entry.txt`
and prints it to stdout. No network, no dependencies, standard library only.

Run it:

    python3 main.py
